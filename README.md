# 英単語マスター (English Vocabulary Master) 仕様書

## 1. 概要
本アプリケーションは、大学受験・TOEIC・英会話等に必要な英単語とその例文を効率的に学習・復習するための単語帳・クイズWebアプリケーション（SPA: Single Page Application）です。

---

## 2. システム構成・技術スタック

| 項目 | 技術・仕様 |
| :--- | :--- |
| **フロントエンド** | HTML5 / Tailwind CSS (CDN) / JavaScript (ES6+ Vanilla JS) |
| **データ保存** | LocalStorage（ブラウザ内永続化ストレージ） |
| **デザイン/UI** | レスポンシブデザイン（PC / モバイル対応）、Interフォント |
| **構築形態** | 単一HTMLファイル（`.html`）完結型 |

---

## 3. 主要機能と詳細仕様

### 3.1 データベース（収録単語）
* **収録数:** 全181単語（CSVフォーマット埋め込み）
* **単語データ構造:**
  * `word`（単語名）: 例 `"abandon"`
  * `meaning`（意味）: 例 `"〜を捨てる・放棄する"`
  * `example`（例文・和訳）: 例 `"The crew had to abandon the sinking ship. (乗組員は沈みゆく船を放棄しなければならなかった)"`
* **自動分割:** 1セクションあたり50単語ずつ自動でセクション1〜4に分割

---

### 3.2 ホーム画面（メインダッシュボード）

#### 💡 学習モード切替（タブ選択）
* **意味当てモード:** 単語が表示され、正しい「日本語の意味」を4択から選択。
* **例文穴埋めモード:** 単語部分が `______` に置き換わった英文が表示され、空欄に入る正しい「英単語」を4択から選択（出題時は日本語訳非表示）。

#### 📊 定着率表示 (進捗プログレスバー)
* **計算式:** 過去に1回以上正解した単語の割合（全正解数 $> 0$ の割合）
* **プログレスバーの色変化:**
  * `~ 29%`: 🔴 赤（未定着）
  * `30% ~ 79%`: 🔵 青（学習中）
  * `80% ~ 100%`: 🟢 緑（定着）
* **全体進捗:** 全181単語の平均定着率を表示。
* **セクション別進捗:** 各セクション（50単語単位）の定着率を表示。

#### ✨ 正解した問題から復習モード
* **対象:** 過去に正解したことがある単語（正解数 $> 0$）のみから集中的に出題。
* **問題数選択:** `10問` / `20問` / `50問`
* ※正解データが存在しない場合はボタンが無効化され注記を表示。

#### 🎲 セクション別・全範囲ランダム出題
* 各セクション（1〜4）または全範囲（181単語）からランダム指定数（`10問` / `20問` / `50問`）で問題を出題。

#### 🗑️ 履歴リセット機能
* 画面右上のボタンよりLocalStorageの学習履歴（`quizHistory`）を削除可能。
* **安全設計:** カスタムモーダルダイアログによる最終確認を実施。

---

### 3.3 クイズ解答画面

#### 📱 クイズUI & レスポンシブ構成
* 現在のモード名（意味当て / 例文穴埋め）と「問題 X / Y」の表示。
* リアルタイム進行度を示す上部プログレスバー。
* 4択選択肢ボタン（左側にショートカットキー用の `1` `2` `3` `4` バッジを表示）。

#### 判定 & 解説表示
* 選択肢選択時（クリックまたはキー入力）に即座に正誤判定。
* **正解時:** 選択ボタンが緑色強調＋ `⭕️ 正解！` バッジ表示。
* **不正解時:** 選択ボタンが赤色、正解選択肢が緑色で強調＋ `❌ 不正解... (未正解に戻りました)` バッジ表示。
* **解説エリア:** 対象単語・意味・例文（英語＋日本語訳）をカード形式で一括表示。

#### ⚠️ 未正解への転落（マスター解除）ロジック
* 再出題時（復習モードや通常テスト）で不正解になった場合、その単語の正解カウントが `0` にリセットされ、「未正解状態（未マスター）」に戻る。

#### ⌨️ キーボード操作対応
* **`1` `2` `3` `4` キー:** 選択肢 1〜4 を選択。
* **`Enter` または `Space` キー:** 解答後の「次の問題へ」の進行。

---

### 3.4 クイズ結果画面

* **結果サマリー:** 正解数 / 出題数（例: `18 / 20`）とスコアに応じたメッセージを表示。
* **解答一覧リスト:** 各問題の出題内容、単語、正解、誤答内容を `⭕️` / `❌` アイコン付きで一覧表示。
* **`Enter` または `Space` キー:** ホーム画面へ復帰。

---

## 4. データ保存仕様 (LocalStorage)

* **キー名:** `quizHistory`
* **フォーマット:** JSON文字列
* **データ構造例:**
```json
{
  "abandon": { "correct": 1, "total": 2 },
  "abolish": { "correct": 0, "total": 1 }
}
```
* **動作ルール:**
  * 正解時: `total` + 1, `correct` + 1
  * 不正解時: `total` + 1, `correct` = 0（リセット）
