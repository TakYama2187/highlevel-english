英単語マスター (English Vocabulary Master) Webアプリ仕様書
1. 概要
本アプリケーションは、大学受験・TOEIC・英会話等に必要な英単語とその例文を効率的に学習・復習するための単語帳・クイズWebアプリケーション（SPA: Single Page Application）です。
2. システム構成・技術スタック
￼ フロントエンド: HTML5 / Tailwind CSS (CDN) / JavaScript (ES6+ Vanilla JS)
￼ データ管理: LocalStorage（ブラウザ内での永続化ストレージ）
￼ UI/デザイン: モバイル＆PC対応レスポンシブデザイン（Interフォント使用）
￼ 構築形態: 単一の ⁠.html⁠ ファイルに全機能（HTML / CSS / JavaScript / データ）を集約
3. 主要機能と詳細仕様
3.1 データベース（収録単語）
￼ 収録数: 全181単語（CSVフォーマットで埋め込み）
￼ 単語データ構造:
￼ ⁠word⁠ (単語名): 例 "abandon"
￼ ⁠meaning⁠ (意味): 例 "〜を捨てる・放棄する"
￼ ⁠example⁠ (例文と和訳): 例 ⁠"The crew had to abandon the sinking ship. (乗組員は沈みゆく船を放棄しなければならなかった)"⁠
￼ セクション分け:
￼ 1セクションあたり50単語ずつ自動分割（セクション1〜4）
3.2 ホーム画面（メインダッシュボード）
1. 学習モード切り替え（タブ選択）
￼ 💡 意味当てモード: 単語が表示され、正しい「日本語の意味」を選択する。
￼ 📝 例文穴埋めモード: 単語部分が ⁠______⁠ に置き換わった英文が表示され、空欄に入る正しい「英単語」を選択する。
※出題時（回答前）にはヒントとなる日本語訳は非表示。
2. 定着率表示 (進捗プログレスバー)
￼ 計算ロジック: 過去に一度以上正解した単語の割合（全正解数 > 0 の割合）に基づいてパーセンテージを計算。
￼ Color表示: 30%未満 (赤)、30%〜80% (青)、80%以上 (緑)。
￼ 全体進捗: 全181単語の平均定着率を表示。
￼ セクション別進捗: 各セクション（50単語単位）ごとの定着率を表示。
3. ✨ 正解した問題から復習モード
￼ 対象: 過去に正解したことがある単語（正解数 > 0）のみを集めた専用出題モード。
￼ 出題問題数: 10問 / 20問 / 50問 から選択。
￼ 正解した問題が存在しない場合はボタンが無効化（メッセージ表示）。
4. セクション別・全範囲ランダム出題
￼ セクション1〜4、または全範囲（181単語）からランダムで指定問題数（10問 / 20問 / 50問）を出題。
5. 🗑️ 履歴リセット機能
￼ 画面右上のボタンから学習履歴（LocalStorageの ⁠quizHistory⁠）を削除可能。
￼ 安全設計: 誤操作防止のため、JavaScript組み込みの ⁠alert⁠ / ⁠confirm⁠ ではなく、カスタムデザインのモーダルダイアログで最終確認を実施。
3.3 クイズ解答画面
1. 出題 UI & レスポンシブ構成
￼ 現在のモード名（意味当て / 例文穴埋め）と「問題 X / Y」を表示。
￼ 上部に進行状況を示すリアルタイムプログレスバー。
￼ 4択の選択肢ボタン（左側に ⁠1⁠ ⁠2⁠ ⁠3⁠ ⁠4⁠ のショートカット数字キー用バッジを表示）。
2. 解答後の判定 & 解説表示
￼ 選択肢をクリック（またはキー入力）すると即座に正誤判定。
￼ 正解時: 選択したボタンが緑色になり ⁠⭕️ 正解！⁠ バッジを表示。
￼ 不正解時: 選択したボタンが赤色、正解の選択肢が緑色で強調表示され ⁠❌ 不正解... (未正解に戻りました)⁠ バッジを表示。
￼ 解説エリア:
￼ 対象単語・意味・例文（英語＋日本語訳）をカード形式で一括表示。
￼ 未正解への転落ロジック:
￼ 再出題時（復習モード等含む）で不正解になった場合、その単語の正解カウントが ⁠0⁠ にリセットされ、「未正解状態（未マスター）」に戻る。
3. キーボード操作対応（アクセシビリティ）
￼ 数字キー ⁠1⁠〜⁠4⁠: 選択肢 1〜4 を選択して回答。
￼ ⁠Enter⁠ または ⁠Space⁠: 回答後に「次の問題へ」進む。
3.4 クイズ結果画面
1. 結果サマリー
￼ 正解数 / 出題数（例: ⁠18 / 20⁠）とスコアに応じたメッセージを表示（「パーフェクト！！」「素晴らしい！」など）。
2. 解答一覧リスト
￼ 各問題の出題内容、単語、正解の意味、間違えた場合は選択した間違った回答を表示。
￼ 正解には ⁠⭕️⁠、不正解には ⁠❌⁠ を表示。
3. キーボード操作対応
￼ ⁠Enter⁠ または ⁠Space⁠: ホーム画面へ戻る。
4. データ保存仕様 (LocalStorage)
￼ キー名: ⁠quizHistory⁠
￼ データ形式: JSON文字列
￼ 構造:
￼ 仕様詳細:
￼ 正解時: ⁠total⁠ + 1, ⁠correct⁠ + 1
￼ 不正解時: ⁠total⁠ + 1, ⁠correct⁠ = 0（リセット）
￼ リロード・ブラウザ再起動を行っても定着率や学習履歴は維持される。
